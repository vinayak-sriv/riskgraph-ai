# Tests

Test folders are split by intent:

- `contract/`: schema and API contract tests.
- `integration/`: multi-service workflow tests.
- `fixtures/`: shared test data.
- `graph_risk/`: deterministic graph, reachability, scoring, and verdict tests.

Current tests cover contracts, graph/risk behavior, platform orchestration, and the
fixture-driven integration path. Java source extraction tests begin in Week 5.
