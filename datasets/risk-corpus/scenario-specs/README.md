# Scenario specifications

`tools/corpus.py:KINDS` defines authorization removal, new public sensitive endpoint,
sensitive-resource exposure, authorization strengthening, safe cosmetic changes,
safe structural refactoring, protected additions, empty changes, ambiguous auth,
and malformed extraction. Each specification is instantiated in ten disjoint
repository identity groups. Files and all expected stage outputs are stored in
the JSONL records and covered by manifest SHA-256 hashes.
